MatrixAI Public API (v1)

Programmatic access to the MatrixAI deep learning optimization engine.

Authentication

All requests require the X-API-Key header. Contact your admin for generation.

POST /api/v1/suggest

Generate optimal parameters from a payload of historical experiments.

curl -X POST https://api.matrixai.com/v1/suggest \
-H "X-API-Key: your_key_here" \
-H "Content-Type: application/json" \
-d '{"material": "WO3", "experiments": []}'
